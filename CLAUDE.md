# FastVocal Comp Basic

Source code of an audio plugin (JUCE 8, CMake).

- When the user asks to build, install, compile or "make it work in my DAW": follow [BUILD_WITH_CLAUDE_CODE.md](BUILD_WITH_CLAUDE_CODE.md).
- When the user asks to modify the plugin: explain what you will change before editing, keep the licence in [LICENSE](LICENSE) (no selling), and give a modified build a different `PRODUCT_NAME` and `PLUGIN_CODE` in `CMakeLists.txt` so it does not replace the original in the DAW.
